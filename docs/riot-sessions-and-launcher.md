# Запись сессий и запуск Riot-игр

Одна запись Riot-аккаунта хранит один логин и защищённый Windows пароль. Три кнопки
в строке запускают League, TFT или Valorant. Данные аккаунтов и формат облачного
хранилища не менялись; старые команды входа и приглашения по-прежнему запускают League.

TFT открывает League Client, проверяет доступность обычной очереди TFT и создаёт
TFT-лобби. Если очередь недоступна, приложение оставляет открытый клиент и сообщает
причину. Valorant запускается через RiotClientServices с выбранным product ID.
Наличие процесса подтверждает запуск Valorant, но не готовность игрового меню.
Смена Riot-аккаунта запрещена при запущенном Valorant или активном матче League.
MFA, обновления, EULA и Vanguard не обходятся. Отмена прекращает ожидание, не убивает игру.

## Записать дома

1. На странице «Логи» нажать «Записать сессию» перед проверкой.
2. Воспроизвести готовность/выбор чемпионов/обрыв подключения.
3. Нажать «Остановить запись», затем кнопку папки рядом.

Файлы находятся в `%APPDATA%/com.rustlm.app/sessions`. Запись явная, не включается
сама после перезапуска. Лимиты: 30 минут и примерно 20 МБ на запись.
Записываются HTTP-ответы и WebSocket-события только перечисленных в коде маршрутов
готовности, gameflow, champ-select, заклинаний и страниц рун; поля фильтруются по разрешённому списку.
Пароли, заголовки, токены, Riot ID, PUUID, чат, друзья и авторизация не записываются.
Game ID и номера игровых ячеек остаются для сопоставления действий внутри сессии.
Пользовательские названия страниц рун удаляются; имя служебной страницы RustLM сохраняется.
Это диагностическая запись выбора, а не полная копия Riot Client или запись экрана.

## Воспроизвести на ПК без League

Из корня проекта:

```powershell
node scripts/lcu-replay.mjs C:/path/to/lcu-recording.jsonl artifacts/lcu-replay.json
```

В другом PowerShell запустить **debug-сборку** с явным локальным подключением:

```powershell
$env:RUSTLM_TEST_LCU = (Resolve-Path artifacts/lcu-replay.json).Path
npm run tauri:dev
```

Нужно включить тот же профиль автоматизации, с которым сделана запись.
Production-сборки не принимают это переопределение. Сервер привязывается только
к 127.0.0.1, использует одноразовый токен и не пересылает запросы в Riot.
WebSocket-события воспроизводятся по времени; GET возвращает последний известный
снимок. Незарегистрированные или несовпадающие записи возвращают 409/404.
Остановка Ctrl+C показывает число ожидаемых/выполненных действий и несовпадений.
Проверять нужно и несовпадения, и оставшиеся невыполненные действия.
Четвёртый аргумент задаёт скорость 0.1–10, например `... artifacts/lcu-replay.json 2`.

Запись не моделирует неизвестные серверные решения и изменение патча, поэтому
повторение реальной записи не заменяет финальный прогон с актуальным клиентом.
Перезапуск симулятора начинает запись заново; повторное подключение LM продолжает
текущую шкалу времени. Для синтетических сценариев остаётся `lcu-simulator.mjs`.

## Запросы и проверки

Запросы разделены на обычные чтения (8), критические чтения готовности/выбора (2)
и записи (2). Загрузка истории не занимает слоты критических операций. Ожидание
слота ограничено тремя секундами. Автоматические повторы записей не добавлены:
потеря ответа не означает, что операция не произошла. Ошибка старого запроса
не сбрасывает уже обновлённые реквизиты подключения.

Идеи очередей изучены в `wnzzer/rank-analysis`, аргументы запуска — в
`dancer/nidalee`; исходники этих приложений целиком не переносились.
Новые зависимости для реализации не добавлялись.

## Источники значков

- League/Valorant: Simple Icons, указанные пользователем через dashboardicons.com;
  SVG получены из пакета simple-icons, https://simpleicons.org/.
- TFT: https://logowik.com/teamfight-tactics-logo-vector-svg-pdf-ai-eps-cdr-free-download-1-14768.html.

Значки поставляются локально; загрузка CDN при показе аккаунтов не требуется.

Для автоматического завершения replay можно отправить строку `stop` в stdin вместо Ctrl+C. Итог сохраняется в `<config>.report.json`: счётчики и вердикт без токена. Код выхода 1 означает пропуски, несовпадения либо ошибку сохранения отчёта; 0 — проверенные действия и сохранённый отчёт.
