# Повторная проверка RustLM — 3 ноября 2026

Проверка поверх локального коммита `19e5571`. Новая версия не создавалась и не публиковалась; интерфейс не менялся.

## Найдено и исправлено

1. **Пропуск следующего ready-check.** У двух разных найденных лобби может совпасть значение timer. Предыдущая дедупликация принимала второе событие за старое. Сначала воспроизведено падение теста (`artifacts/audit-repeat-before.log`): после успешного первого принятия второе оставалось `None`. Удалена дедупликация по таймеру; перед действием проверяется свежий ready-check, одновременные действия по-прежнему ограничены блокировкой. Тест проверяет два последовательных лобби и отсутствие лишнего POST при повторе старого события.
2. **Скрытая ошибка запуска League.** После подтверждённой авторизации ошибка `launch_league_via_rc` только записывалась в лог, затем выполнялся путь DONE. Теперь ошибка возвращается пользователю, успешное завершение не объявляется. Также оставшийся вспомогательный цикл ожидания RSO использует трёхзначное состояние: неизвестный результат не равен подтверждённому выходу.
3. **Код подключения зависел от конфликтов аккаунтов.** Предыдущее исправление вызывало полную синхронизацию при незавершённой ротации ключа. Она могла завершиться SYNC_CONFLICT и не дать получить исправный код. Теперь выполняется только GET и проверка ключа шифрованного документа, без слияния, PUT или изменения аккаунтов. Проверено сохранение baseline при восстановлении ключа, даже когда слияние аккаунтов конфликтует.
4. **Ошибки отключения автозапуска скрывались.** Удаление записи Windows Run игнорировало все ошибки. Теперь отсутствие значения допускается, а отказ в доступе возвращается вызывающему коду. Native-тест использует отдельный временный ключ HKCU: проверяет отказ через read-only handle, сохранность значения, удаление и повторное отключение уже отсутствующего значения. Настоящий ключ автозапуска LM не изменялся.
