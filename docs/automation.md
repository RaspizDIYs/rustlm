# Автоматизация выбора чемпионов

В обычных и ранговых играх можно включить «По ролям» и заполнить Топ, Лес, Мид, ADC и Поддержку. Для каждого профиля сохраняются три приоритета пика, бан, заклинания и страница рун. Незаданный профиль роли не наследует общий пик. Без переключателя сохраняется прежний общий профиль.

ARAM и ARAM: Хаос используют отдельные профили. Начальный выбор ограничен `subset-champion-list` текущего игрока; приоритеты не расширяют выданный игрой набор. Общая скамейка используется только с включённым переключателем, в FINALIZATION после открытия пула. Доступность и ограничения обмена дополнительно проверяет клиент. Если предпочтений нет среди доступных, текущий чемпион сохраняется.

В Хаосе авторуны и автобан не выполняются. В обычном ARAM авторуны доступны, Изнурение разрешено; Кара и Телепорт недоступны в обоих вариантах. Клиентские ограничения заклинаний, включая обязательные заклинания роли, проверяются перед записью. При недоступном API ограничений текущие заклинания сохраняются.

На Арене доступны обычные приоритеты и «За наковальню»: сначала предпочтения среди Crowd Favorites, затем первый доступный Crowd Favorite. «Вручную / Bravery» отключает автопик; автоматизация не нажимает случайный выбор и не покупает бонусы. Руны и заклинания задаёт игра.

Неизвестные режимы и наблюдение не обрабатываются. Перед подтверждением повторно проверяются лобби, роль и текущий ход. Чужие страницы рун не удаляются: при отсутствии свободного места клиент может отказать в создании страницы RustLM.

Проверки на синтетических данных не заменяют прогон в актуальном клиенте: LCU — внутренний API, его поля и возможности могут меняться. Нужна проверка реальных лобби RU/EUW для каждого режима, включая карточки, таймер скамейки и Crowd Favorites.

Источники правил: [ARAM](https://support.riotgames.com/ms-my/league-of-legends/gameplay/aram-game-mode), [Хаос](https://support.riotgames.com/en-us/league-of-legends/events/league-of-legends-aram-mayhem-game-mode), [Арена](https://support.riotgames.com/en-us/league-of-legends/gameplay/league-of-legends-arena-game-mode). Структуры LCU сверены с [описанием API](https://github.com/KebsCS/lcu-and-riotclient-api) и [реализацией subset API](https://github.com/LeagueAkari/LeagueAkari/blob/main/src/shared/http-api-axios-helper/league-client/lobby-team-builder.ts).
