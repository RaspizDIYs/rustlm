# Unglitch в RustLM

Самостоятельная реализация функций восстановления интерфейса League, вдохновлённая [League-Unglitch](https://github.com/MaciejGorczyca/League-Unglitch). Код и ресурсы исходного проекта не включены: на момент просмотра его репозиторий не указывает лицензию.

- Перезагрузка: POST `/riotclient/kill-and-restart-ux`.
- Фоновый режим: POST `/riotclient/kill-ux`.
- Восстановление: POST `/riotclient/launch-ux`.
- Принудительный вариант: завершение только `LeagueClientUxRender.exe` из папки текущей LCU-сессии. Путь проверяется через тот же Windows handle, которым завершается процесс. Если интерфейс нельзя определить однозначно, операция отклоняется.

Запросы идут через существующее подключение LM к loopback LCU. Процесс игры, LeagueClient.exe, Riot Client и Vanguard не завершаются; файлы игры, hosts, DNS и Zapret не меняются. Права администратора автоматически не запрашиваются.

Операции сериализованы, ограничены таймаутом 25 секунд и пишут в журнал только вид действия и подтверждение результата. Токены и ответы LCU не попадают в этот журнал. API клиента Riot может измениться; отсутствие доджа и восстановление сессии не гарантируются.

Проверки на реальном клиенте: обычная перезагрузка в лобби; закрытие/восстановление окна с живым LeagueClient.exe; перезапуск рендера; смена порта LCU; повторный запуск клиента. Выбор чемпионов тестировать отдельно, с явным согласием игрока. На машине без установленной League эти проверки не подтверждены.
