# RustLM 0.5.22 — исправление автопринятия

В 0.5.21 запуск Polling и WebSocket зависел от ответа вспомогательного
`/lol-service-status/v1/shard-data`. После корректной обработки HTTP-ошибок
ответ 404 оставлял слушатели в бесконечном ожидании, хотя сам ready-check мог
работать. В 0.5.22 эта зависимость убрана: WebSocket проверяется своим handshake,
а Polling обращается непосредственно к рабочему API подтверждения игры.

Настройки, выбранный метод и проверки ошибок основных запросов сохранены.
Регрессионный тест сначала воспроизвёл отказ Polling на старом коде, затем
прошёл для Polling и WebSocket при постоянном 404 вспомогательного адреса.
Это подтверждает исправление воспроизведённого условия; домашний живой прогон
остаётся необходимым.

Все возможности 0.5.21 сохранены. [Домашний чек-лист](https://github.com/RaspizDIYs/rustlm/blob/v0.5.22/docs/home-validation-checklist.md)
также приложен отдельным файлом к релизу.

Обновитесь через LM либо установите `RustLM_0.5.22_x64-setup.exe`.
