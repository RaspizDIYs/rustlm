# RustLM 0.5.21

- Unglitch: фоновое наблюдение и одна мягкая попытка восстановления интерфейса; автоматический перезапуск заблокирован во время поиска, подтверждения игры, выбора чемпионов и матча.
- Внешняя диагностика без Pengu: доступные элементы Windows UI Automation, длительность запросов LM и отдельное подтверждение результата автопика/автобана через LCU.
- LCU: структурный разбор событий, тайм-аут и heartbeat WebSocket, свежий снимок после переподключения, корректная обработка HTTP-ошибок.
- ARAM: повторная проверка сессии, чемпиона, доступности и времени перед обменом на скамейке.
- Ограниченный диагностический отчёт с категориями, временем и кодами ответа; без сырых URL и содержимого запросов/ответов.
- Локальный тестовый LCU для разработки и 119 домашних проверок.

**Домашний чек-лист:** [открыть в репозитории](https://github.com/RaspizDIYs/rustlm/blob/v0.5.21/docs/home-validation-checklist.md). Этот же файл приложен к релизу.

Автоматические и синтетические проверки не подтверждают работу всех режимов настоящей League, распознавание реального зависшего окна, ремонт на каждом провайдере или синхронизацию двух физических ПК. Открытые сценарии перечислены в чек-листе. UIA может видеть только часть интерфейса; DOM, все анимации и все внутренние запросы League не перехватываются.

Для установки скачайте `RustLM_0.5.21_x64-setup.exe` или воспользуйтесь встроенным обновлением. Файл `latest.json` и подпись установщика предназначены для автообновления.
