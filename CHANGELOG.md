# Changelog

## [0.5.25] - 2026-11-06
- Исправлен небезопасный путь перезапуска рендера Unglitch: используется штатный restart UX.
- Обновлены правая панель друзей/пати, персональные цветные статусы и компактные инструменты.
- Добавлены обзор при запуске, запись/воспроизведение LCU и проверки конкурентных переходов.

## [0.5.22] - 2026-11-03
- Исправлена блокировка запуска Polling и WebSocket при недоступном вспомогательном status API
- Добавлен регрессионный тест: автопринятие работает при постоянном HTTP 404 на вспомогательном адресе
- Обновлён домашний чек-лист с подтверждённым сбоем версии 0.5.21

## [0.5.21] - 2026-11-02
- Unglitch: фоновое наблюдение и одна мягкая попытка восстановления с защитой поиска, выбора чемпионов и матча
- Диагностика без Pengu: доступные элементы Windows UIA, время запросов LM и подтверждение пиков через LCU
- LCU: структурный разбор событий, снимок состояния при переподключении, heartbeat и проверка HTTP-ошибок
- ARAM: повторная проверка доступности чемпиона, сессии и оставшегося времени перед обменом
- Диагностический отчёт без сырых URL, тел запросов и данных аккаунтов
- Домашний чек-лист: 119 сценариев; реальные проверки League, второго ПК и провайдера отмечены отдельно
- Инструменты разработки: локальный тестовый LCU и сценарии восстановления без установленной игры

## [0.5.1] - 2026-10-29
- ARAM и Хаос: горизонтальная лента иконок приоритетов с отдельным удалением каждого чемпиона
- На странице логов кнопки и фильтры выровнены по общим границам
- Аккаунты и друзья: компактный дизайн, фиксированные кнопки и поиск, вход рядом с меню действий
- Сортировка заметок, аккаунтов, серверов и логинов; панель клиента закреплена под списком
- Последние 20 матчей: единая раскрывающаяся строка, горизонтальная лента W/L и KDA с прокруткой колёсиком
- Ранги: иконка, дивизион и LP; реальные значки Discord и GitHub
- Друзья: аватарки, отметки League и GoodLuck, объединённый список и подтверждение удаления
- Заявки отделены от профиля; меню содержит только входящие запросы
- Компактная боковая панель сохраняет страницы, сворачивание, версию, заявки и профиль
- Автоматизация: отдельные режимы обычных игр, ARAM, Хаоса и Арены; профили пяти ролей
- Автопик и автобан включаются сразу для всех обычных ролей; лес всегда сохраняет Кару
- До 30 приоритетов ARAM и Хаоса, выбор из своих карточек и открытой общей скамейки
- Арена: выбор по приоритету или за наковальню; ручной Bravery
- Заклинания и руны учитывают ограничения режима; чужие страницы рун сохраняются
- Подсказки скрываются при прокрутке; выбранные картинки подсвечиваются, поиск выделяет совпадения
- Все страницы оформлены компактно; история изменений открывается по нажатию на версию
- Настройки: короткие описания, пояснение выбранного метода автопринятия, переключатель анимаций
- Сохранение рун ожидает результат; при ошибке редактор остаётся открытым
- Настройки сохраняются с резервной копией; ошибки записи возвращают прежнее значение
- Исправлены фильтры журналов; просмотр получает только новые строки и хранит последние 2000
- Снижена лишняя работа при сохранении автоматизации; фоновые опросы приостанавливаются в скрытом окне
- Исправлены очистка подписок, доступные названия переключателей и прокрутка на краях ленты матчей

## [0.3.0] - 2026-05-02

### Новое
- Раздел «Конфиги» (/configs) для управления PersistedSettings.json — главным файлом настроек League of Legends
- Защита от перезаписи (read-only toggle) — клиент не сможет затереть настройки при выходе из игры
- Библиотека пресетов настроек: создание из текущих, применение, удаление
- Экспорт и импорт `.lolcfg` файлов для шаринга пресетов между устройствами
